文字算機率，影像學去噪

文字生成

文字 → Token ID → Embedding
→ Self-Attention → 下一個 Token

\[P(w_t\mid w_1,\ldots,w_{t-1})\]

機率高的接續，仍可能缺乏事實根據。

影像生成

Forward：圖片 → 加高斯雜訊 → 雜訊
Reverse：雜訊 → 逐步去噪 → 新圖片

\[x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon\]

像雕刻家逐步修整，每一步處理局部修正。

講者小抄 · 13 秒（N / S）

建議講稿：文字模型根據上下文預測下一個 Token，機率高不代表事實正確。影像擴散則學習逐步去噪，就像雕刻家一步步修整作品。

補充說明與證據

文字先由模型專屬 Tokenizer（例如子詞切分）變成 ID，再查表成 Embedding。Transformer 依上下文估計下一個 Token，這個目標本身不保證事實正確。
Forward 的 epsilon 服從 N(0,I)，alpha_bar_t 是累積噪聲排程；訓練可直接抽樣 t 及 x_t，不必走完所有前向步。Reverse 由噪聲預測器 epsilon_theta(x_t,t) 配合採樣器更新；經典 DDPM 可用 U-Net，其他架構也存在。
\[\mathcal L=\mathbb E_{x_0,t,\epsilon}\left[\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2\right]\]
1000 步是經典設定例子，不是所有模型固定值。雕刻家只是教學比喻；單步與蒸餾生成方法也存在。
一手來源：DDPM

Prompt 如何控制去噪方向？

文字 → CLIP / T5 → 文字向量（K、V）
影像特徵（Q）→ Cross-Attention → 條件去噪

\[\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\]

VAE 範例：512 × 512 × 3 → 64 × 64 × 4 → 去噪 → 解碼

\[s_\theta(x_t,t)\approx\nabla_{x_t}\log p_t(x_t)\approx-\frac{\epsilon_\theta(x_t,t)}{\sqrt{1-\bar\alpha_t}}\]
展開 GAN / VAE / Diffusion 比較
方法機制常見優點常見限制
GAN生成器／判別器博弈快速生成訓練不穩、模式崩潰
VAE潛變量編碼與重建可學習潛空間傳統設定可能較模糊
Diffusion學習多步去噪高品質與條件控制多步採樣成本
講者小抄 · 13 秒（N / S）

建議講稿：文字會先編碼，再用交叉注意力引導去噪。部分模型先把圖像壓縮到潛空間，減少運算；Score 描述加噪分布的機率梯度。

補充說明與證據

以經典文字條件 Latent Diffusion 為例：文字編碼器產生條件向量，交叉注意力讓影像特徵取得文字條件。不是所有生成模型都使用相同 U-Net 或 CLIP。VAE 範例長寬各縮成 1/8，空間位置是 1/64；通道數也改變，不能直接說總資料量就是 1/8。
Score 是時間 t 的加噪分布對數梯度，噪聲預測與 Score 的關係包含負號與尺度。「爬山」可描述局部方向，但採樣動力學並非把全部樣本推到同一山頂。VAE 潛空間壓縮與 GGUF 權重量化節省不同資源。
